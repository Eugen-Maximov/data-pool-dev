Одноручный экзотический дробовик с боезапасом в 2 выстрела, который стреляет с помощью навыка ""Оружие Крупного Калибра"" вместо навыка ""Тактическое Оружие"".
Механически этот огнемет представляет собой дробовик, который может стрелять только зажигательными снарядами (стоимость боеприпасов для этого оружия такая же, как и для зажигательных снарядов). Помимо основного урона, ваши цели загораются и продолжают гореть, до тех пор, пока они не используют действие, чтобы потушить себя, они получают 4 урона напрямую в ПЗ в конце своего хода. Если они уже горели, эффект поджигания увеличивает интенсивность горения на бОльшую. Несколько раз этот эффект не суммируется. Урон, наносимый этим оружием, не может вызвать критическое ранение, и его нельзя использовать для прицельных выстрелов.
